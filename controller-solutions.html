Match · Modify · Customize

Flexible Levels of Customization

The appropriate level depends on the application, available solutions and commercial requirements.

  1. 01 /

    Standard Controller Sourcing

    Identify a suitable existing controller based on electrical requirements, load type, control method, dimensions, connectors and application.

  2. 02 /

    Existing Product Modification

    Modify an existing controller where feasible. Review connector changes, PCB dimensions, enclosure compatibility, input/output configuration, voltage/current requirements, sensor inputs, relay outputs, control parameters and communication interfaces.

  3. 03 /

    Semi-Custom Controller

    Adapt existing hardware or firmware for an OEM application. Review application-specific control logic and operating behavior: timing sequences, sensor-based control, motor logic, temperature control, fan/pump operation, relay sequences, fault handling, alarms and user-input logic.

  4. 04 /

    Custom Controller Board

    For suitable projects, coordinate an application-specific board based on electrical, functional and interface requirements, mechanical constraints, target cost and production quantity.

A new PCB is not required for every project. Project feasibility can be evaluated during the RFQ process.

OEM project workflow

From Requirement to Production

A coordinated process with the customer and suitable manufacturing and engineering resources.

  1. 01 /

    Requirement Review

    Review the application description, sample, drawing, specification, BOM and functional requirements supplied by the customer.

  2. 02 /

    Solution Selection

    Determine whether an existing controller, modified controller, semi-custom solution or full custom controller board best fits the project.

  3. 03 /

    Technical Review

    Review voltage, current, inputs/outputs, sensors, control logic, communication, dimensions and environmental requirements.

  4. 04 /

    Sample / Prototype

    Where applicable, coordinate samples or prototypes for evaluation.

  5. 05 /

    Customer Validation

    Customer testing and functional verification inform specification adjustments before production approval.

  6. 06 /

    Production Supply

    After approval, coordinate production, documentation, quality requirements, order management and logistics support.
